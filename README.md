##### **在降级BIOS前，请先阅读完本文本！**

###### **降级原理：**

较新出厂的机器所带的BIOS（如20版本、24版本）默认开启了写保护，无法通过FPT刷写解锁后的BIOS版本，但BIOS是需要给官方版本的BIOS升级留门的，所以先通过“升级”官方的未开启写保护的BIOS版本（16版本），再通过fpt刷写解锁后的BIOS版本即可。

###### **解锁流程：**

假设你的机器BIOS版本为**20版本**，那么解锁顺序如下

20版本（未解锁）→ 使用fpt.efi备份你的未解锁的20版本→进入Windows解锁你的20版本，放到你的启动盘，并着手降级到16版本→刷入解锁的20版本

###### **刷机前提示：**

**一定要备份自己原机的BIOS**，并且建议使用你原机的BIOS进行解锁刷入，使用我提供的BIOS不适配有出现bug的可能。

##### **针对英特尔ultra200s（耀世）：**

里面有【BIOS (N.1.13MRO16)】X6AR5xxxN113MRO16\_CAP，打开确认输入y就行了，但是要注意主板型号（可以通过打开图吧工具箱查看）是X6AR5开头，其他的版本不确定适不适配，刷bios有风险，刷前做好备份防止机器变砖。

bios文件夹下共有6个版本的bios：

16.fd

16\_unlock.fd

20.fd

20\_unlock.fd

24.fd

24\_unlock.fd

16.fd/20.fd/24.fd是原版的bios，后缀unlock是已经解锁后的bios，可以直接由开了写保护的版本通过exe降级到16版本后，直接进行fpt刷写，省略了一个先备份再解锁再重启刷写的步骤。

通过测试发现24版本/20版本的优化相比于16是更好的。对于一些内存小参，20/24版本更容易过测，16版本就会报错。



##### **针对amd平台（蛟龙、苍龙等cpu为AMD的机子）：**

找一个u盘，格式化为fat32格式，把UMAF\_BETA.zip解压到u盘。具体使用方法去b站搜蛟龙bios解锁。使用方法一样的。这个不需要刷bios，风险更低，也只适用amd平台。有的up主放出来的umaf可能会存在功耗分配问题，这个umaf\_beta版本解锁（五月份测试）是不会有cpu显卡功耗分配问题的，也可以直接去github搜umaf\_smokeless去下载最新的版本。
